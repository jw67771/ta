# VR 적립식 중계기 (라오어 VR 7기)

무한매수법과 완전히 다른 전략이다. 목표 평가금 `V` 를 매 사이클(2주) 갱신하고,
평가금이 밴드 밖으로 나가면 그만큼만 사고팔아 `V` 로 되돌린다.

## 계산 규칙

```
              Pool     (E - V1)
V2 = V1  +  ------  +  ----------  ±  적립금
                G      2 * sqrt(G)

최소값 = V2 x 0.85        최대값 = V2 x 1.15
```

| 기호 | 뜻 |
|---|---|
| `V` | 목표 평가금. 계좌 주식 평가금이 이 값이 되도록 리밸런싱 |
| `E` | 직전 사이클 마지막 평가금 |
| `Pool` | 직전 사이클 마지막 예수금 (적립금 더하기 **전**) |
| `G` | 분모 상수. VR 7기는 **10** |
| 적립금 | 2주마다 $100 (1배 기준). 적립식은 `+`, 인출식은 `-` |

밴드는 반올림한 `V` 에서 계산한다. VR 7기 1주차 자료로 검증:
`V1=71.17, Pool=28.83, E=71.17, G=10, 적립금=100` → `V2=174.05`,
최소 `147.94`, 최대 `200.16` (센트까지 일치).

`N` 배수로 굴리면 개수·예수금·적립금이 전부 `N` 배가 된다.

## 주문표 (한 칸에 1주씩, 지정가)

```
매수점 = 최소값 / 보유개수      매도점 = 최대값 / 보유개수
```

그 가격이 되면 보유 평가금이 정확히 밴드 끝에 닿는다. 한 주 사고팔아 평가금을
밴드 안으로 되돌리는 것이 VR 의 리밸런싱이다. 사면 보유개수가 늘어 다음 매수점이
더 낮아지고, 팔면 줄어 다음 매도점이 더 높아진다. 매수 사다리는 Pool 이 감당하는
데까지만 건다.

VR 6기 3주차 자료로 검증 (최소 224.14 / 최대 303.24 / 보유 3주 / Pool 144.40):

| | 매수점 | Pool | | 매도점 | Pool |
|---|---|---|---|---|---|
| 3→4주 | 224.14/3 = **74.71** | 69.69 | 3→2주 | 303.24/3 = **101.08** | 245.48 |
| 4→5주 | 224.14/4 = **56.04** | 13.65 | 2→1주 | 303.24/2 = **151.62** | 397.10 |

5→6주는 44.83 인데 Pool 이 13.65 뿐이라 걸지 못한다. 자료의 표도 여기서 끊긴다.

## VR 7기 진행

- 2026-08-21 (금) 시작. 0원부터, 2주마다 $100 적립. 11년 목표 40만달러
- 8/21 종가 71.17 에 1개 매수 → 0주차 완료
- 1주차 사이클 (8/24 ~ 9/4): 8/24 하루만 LOC 79달러에 1개 매수시도.
  매도점(200.16)이 현실과 너무 멀어 매도는 걸지 않는다
- 결과적으로 2개 보유로 이 사이클을 지나가고, 9/5~9/6 에 3주차 안내가 나온다
- 초반 3~4달은 계속 매수만 나온다

## 사용법

```sh
python3 -m vr.cli init --multiplier 1 --pool 200 --week 1 --v 174.05 --invested 200
python3 -m vr.cli trade --price 71.90 --qty 1 --date 8/24
python3 -m vr.cli cycle --price 72.30          # 사이클 마지막 종가로 다음 V 계산
python3 -m vr.cli status
```

상태는 `vr/state/tqqq_vr7.json`.

## 검증 현황

| 자료 | 검증 항목 |
|---|---|
| VR 7기 1주차 | V 174.05 / 최소 147.94 / 최대 200.16 / Pool 128.83 |
| VR 6기 3주차 | V 263.69 / 최소 224.14 / 최대 303.24 / Pool 144.40 |
| VR 6기 3주차 | 매수 사다리 74.71·56.04, 매도 사다리 101.08·151.62 와 Pool 잔액 |

VR 7기 1주차는 매수점(147.94)이 Pool(128.83)을 넘어 사다리를 한 칸도 못 건다.
라오어가 "표는 비현실적이니 무시하고 79달러에 1개" 라고 한 상황이 정확히 이것이다.

배당(Pool 정리표의 `배당` 행) 처리는 아직 실제 사례를 못 봤다. TQQQ 배당이
들어오는 분기에 자료를 받으면 대조한다.
