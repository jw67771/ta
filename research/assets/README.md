# 슬라이드·차트 캡처 보관소

강의 슬라이드나 차트 캡처 이미지를 여기에 둡니다.

## 파일명 규칙

영상 노트 파일명과 같은 stem에 번호를 붙입니다. 노트와 이미지가 1:1로 붙어 있어야
나중에 원문을 다시 확인할 수 있습니다.

```
assets/membership-01-starbucks-1.png
assets/membership-01-starbucks-2.png
assets/2026-08-20-samsung-q2-1.png
```

## 노트에서 참조하는 법

영상 노트 본문에서 상대경로로 링크합니다.

```markdown
![1화 슬라이드](../assets/membership-01-starbucks-1.png)
```

## 왜 원본을 남기는가

노트의 전사(轉寫)는 아무리 조심해도 옮기는 사람의 해석이 섞입니다. 원본 캡처가 함께 있으면
나중에 "정말 그렇게 적혀 있었나"를 되짚을 수 있습니다. 이 아카이브가 근거 자료로 쓰이려면
그 되짚기가 가능해야 합니다.

## 주의

이미지는 텍스트와 달리 git에서 diff가 되지 않고 용량이 누적됩니다. 캡처는 원본 해상도 그대로
넣기보다 읽을 수 있는 선에서 줄여 넣는 편이 좋습니다.
