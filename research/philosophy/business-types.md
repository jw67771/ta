## 원칙

사업을 **5가지 종류**로 나누고, 유형마다 재무제표에서 확인할 항목과 위험을 달리 본다.

**아직 전체 목록이 확인되지 않았다.** 지금까지 드러난 것은 다음과 같다.

| 종류 | 확인된 화 | 공통점 / 확인 항목 | 위험 |
|---|---|---|---|
| **기술력** | 17화 | 손익계산서의 R&D가 많음 | 기술 변화를 잘 파악해야 함 |
| **브랜드** | 19화 | 영업현금흐름 〉 순이익 · 배당/자사주매입 적극적 · **소비자로서 평가 가능** | (슬라이드에 없음) |
| (지적재산권?) | 3화에서 무디스를 '지적재산권 / 브랜드'로 표기 | 로열티·수수료 수취 | — |
| (미확인) | | | |

## 왜 유형을 나누는가

**유형마다 확인할 재무제표 칸이 달라지기 때문이다.** 11~16화에서 재무제표 읽는 법을 가르친 뒤
17화부터 유형별 적용으로 넘어가는 순서가 그것을 보여준다.

| | 기술력 | 브랜드 |
|---|---|---|
| 현금의 방향 | R&D로 나간다 | 주주에게 돌아온다 |
| 볼 표 | 손익계산서 (R&D) | 현금흐름표 (OCF vs 순이익) |
| 9화 분류 성향 | 재개발 쪽 | 빌라~아파트 쪽 |

마지막 행은 내 추론이다.

## 반례 / 충돌

- **목록이 미완이다.** 5가지 중 2~3가지만 확인됐다. 나머지가 나오기 전까지 이 원칙은
  분류 체계가 아니라 사례 모음에 가깝다.
- **기술력 유형은 3화와 부딪힌다.** "기술 변화를 잘 파악해야 함"과
  ["5년 뒤에도 성장한다는 확신"](certainty-over-price.md)은 서로 어렵게 만든다.
  기술 변화가 빠른 산업일수록 5년 확신을 세우기 힘들다. 18화의 AMAT은 '장비 1위'라는
  시장 지위로 그 공백을 메웠다.
- **브랜드 유형의 위험이 비어 있다.** 기술력에는 위험이 명시됐는데 브랜드에는 없다.
  브랜드도 소비 트렌드로 낡는다.
- **"소비자로서 평가 가능"은 양날이다.** 개인 투자자가 직접 검증할 수 있다는 점에서
  3화의 "사업 내용을 읽어라"를 실행 가능하게 만들지만, 내 경험은 표본이 하나다.
  "내가 좋아하니 좋은 회사"라는 편향에 빠지기 쉽다.

## 내 적용

- 종목 노트의 사업 개요에 유형을 적고, **그 유형에 해당하는 확인 항목**을 검증 포인트에 넣는다.
  기술력이면 R&D 비중, 브랜드면 영업현금흐름 대 순이익 배수.
- 5가지 목록이 완성되면 이 노트를 갱신한다. 21화 이후에 나올 가능성이 높다.
