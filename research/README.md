# 성환김 투자 리서치 아카이브

유튜버 **성환김**의 투자철학과 종목분석을 기록해 두고, 내 투자 판단에 참고하기 위한 저장소입니다.

## 이 저장소가 지키려는 원칙

1. **원문이 먼저다.** 모든 기록은 영상 노트(`videos/`)에서 출발합니다. 종목 분석과 투자 원칙은
   영상 노트를 출처로 참조해야 하고, 참조 없는 문서는 검증에서 걸러집니다.
2. **그의 말과 내 생각을 섞지 않는다.** 모든 템플릿에 "내 메모 / 내 판단" 절이 따로 있습니다.
   나중에 이 아카이브를 다시 읽을 때, 어디까지가 인용이고 어디부터가 해석인지 구분되지 않으면
   기록의 가치가 사라집니다.
3. **의견은 덮어쓰지 않고 쌓는다.** 종목 노트의 `views`는 시간순 이력입니다. 과거 의견을 지우면
   "그때 그 판단이 맞았나"를 되짚을 수 없습니다.
4. **불확실한 건 불확실하다고 적는다.** 영상 노트의 `confidence`, 원칙의 `status: tentative`가
   그 자리입니다.

## 디렉터리

```
research/
├── videos/       영상별 원본 기록 (사실 근거)
├── stocks/       종목별 의견 이력
├── philosophy/   반복 확인된 투자 원칙
├── tools/        검증·색인 스크립트
├── INDEX.md      자동 생성 색인 (직접 수정 금지)
└── SCHEMA.md     YAML 필드 정의
```

## 새 영상을 정리하는 순서

```bash
# 1. 영상 노트 생성 (파일명 날짜는 영상 공개일)
cp research/videos/_template.md research/videos/2026-08-20-samsung-q2.md

# 2. front matter와 본문을 채운다. 발언은 원문에 가깝게.

# 3. 언급된 종목마다 stocks/<티커>.md 의 views에 항목을 추가
#    (파일이 없으면 _template.md 를 복사해서 새로 만든다)

# 4. 반복 확인된 사고방식이면 philosophy/ 로 승격

# 5. 검증하고 색인 갱신
make research
```

한 번만 나온 말은 원칙이 아닙니다. 영상 노트에 남겨 두었다가, 다른 영상에서 같은 이야기가
다시 나오면 그때 `philosophy/`로 올리고 `status`를 `confirmed`로 바꾸세요.

## 명령

```bash
pip install -r research/requirements.txt

make research           # 검증 + 색인 갱신
make research-validate  # 검증만
make research-index     # 색인만

python3 research/tools/build_index.py --check   # 색인이 최신인지 확인 (CI용)
```

검증기가 잡아내는 것: 필수 필드 누락, 존재하지 않는 출처 참조, 파일명과 어긋난 티커/ID,
잘못된 열거형 값(스탠스·시장·카테고리), 파일명 날짜와 `published` 불일치, 인용되지 않은 영상 노트.

## 티커 표기

한국 종목 코드는 **반드시 따옴표로** 감싸세요. `ticker: 005930` 은 YAML이 숫자 `5930`으로
해석해 앞자리 0이 사라집니다. `ticker: "005930"` 이 맞습니다.

## 주의

여기 담긴 내용은 **제3자의 공개 발언을 기록한 것**이지 투자 권유가 아닙니다.
기록이 정확하다고 해서 그 판단이 옳다는 뜻도 아닙니다. 최종 투자 판단과 그 결과는 내 몫입니다.

기록할 때는 원문을 그대로 옮기고, 기억에 의존한 부분은 `confidence: low`로 표시하세요.
추측으로 채운 내용은 나중에 사실로 착각하게 되고, 그게 이 아카이브를 가장 위험하게 만드는 방식입니다.
